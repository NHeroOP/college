# College Website - HTML and CSS

This is a simple college website made only with HTML and CSS.

## Files
- index.html - Home page
- about.html - About page
- faculty.html - Faculty page
- students.html - Students page
- gallery.html - Photo Gallery
- admission.html - Student Admission Form
- style.css - External CSS
- images/ - Simple SVG image assets

## How to run
Open `index.html` in a web browser.

## Easy customization
Change the college name, student names, faculty names and contact details directly in the HTML files.
